# 🎯 Dart Basics Learning Project

## 🎯 About Dart
Dart is a:
- High-level programming language  
- Object-oriented language  
- Developed by Google  

It is mainly used for Flutter app development (Android, iOS, Web).

---

## 📖 Project Description
This project is created for learning Dart basics to advanced concepts such as:
- Variables  
- Data Types  
- Functions  
- Loops  
- Object-Oriented Programming (OOP)  

---

## 🧠 Dart Data Types Covered

### 🟢 Basic Types
- int → 10  
- double → 10.5  
- String → "Hello"  
- bool → true / false  

---

### 🟡 Intermediate Types
- List → [1, 2, 3]  
- Map → {"name": "Badol"}  
- Set → {1, 2, 3}  

---

### 🔴 Advanced Types
- Function → () {}  
- dynamic → any type  
- Null safety → null handling
